## Proyecto destacado

### [BiblioUMAG](https://github.com/Dysnomia9/BiblioUMAG_publico_web_v2) · Sistema de gestión bibliotecaria

Plataforma web que reemplaza a Horizon (SirsiDynix) en la Biblioteca de la Universidad de Magallanes.

| | |
|---|---|
| **Stack** | Vue 3 + Tailwind + Pinia · Laravel + PostgreSQL · Docker |
| **Módulos** | Entradas por QR, préstamos de libros y recursos, reservas de salas en horario continuo, cola de espera FIFO, catalogación MARC, multas, reportes y portal de autoservicio |
| **Seguridad** | Autenticación Sanctum con dos guards independientes y 23 permisos granulares por rol |
| **Calidad** | Más de 500 pruebas automatizadas sobre un modelo de 23 tablas, con cobertura de condiciones de carrera y restricciones de integridad |
| **Escala probada** |
